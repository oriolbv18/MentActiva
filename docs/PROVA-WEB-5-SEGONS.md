# «Test de la mare»: la web s'entén en 5 segons? (preparat per a l'Oriol)

**Objectiu:** que una persona que no coneix el projecte entengui en 5 segons **què és MentA** i **què pot fer ara**.

## Com fer-ho (5 minuts amb algú real)
1. Tria algú que no conegui MentA (un familiar, un veí, algú gran si pot ser; una persona que treballi en una residència, millor).
2. Obre la web en un mòbil (és com la veurà la majoria). **No expliquis res.** Deixa-la 5 segons i gira el mòbil cap a tu.
3. Fes les 3 preguntes **en aquest ordre** i apunta la resposta literal, sense ajudar:

| # | Pregunta | Resposta correcta (ha de dir alguna cosa així) | Resposta literal | ✓ / ✗ |
|---|---|---|---|---|
| 1 | «Què és això? De què va?» | «Una app de jocs per a la gent gran» / «per mantenir la ment activa». | | |
| 2 | «Per a qui és?» | «Per a l'avi (o la persona gran) i per a qui la cuida». | | |
| 3 | «Què faries ara per provar-la?» | «Premo *Prova l'app*» (o «el botó taronja»). | | |

**Aprovada** si les 3 surten correctes sense ajuda. Si falla la 1 → revisar el titular i el subtítol del hero; si falla la 2 → el subtítol; si falla la 3 → el botó taronja (mida, color, posició).

## Preguntes de seguiment (opcionals, 2 minuts més)
- «Què t'ha cridat més l'atenció?» (esperem: el mòbil o l'Elefant).
- «Hi ha res que t'hagi fet desconfiar o no t'hagi quedat clar?» (apunta-ho tal qual).
- «Tu ho posaries a l'abast d'un avi? Per què sí o per què no?»
- Si és d'una residència: «Si volguessis una demo, saps què fer?» (esperem: *Demana una demo*).

## Què no s'ha de fer
No ensenyis la web amb explicacions, no diguis «mira, scrolleja». El test mesura la primera pantalla. I **no n'extreguis cap xifra** («9 de 10 ho entenen»): amb poques persones són opinions, no dades (i a la web no n'inventem).
